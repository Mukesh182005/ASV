# ASV Dataset Research Notes

## Goal
Find EMG datasets suitable for:
- Silent speech recognition
- Facial muscle activity
- Jawline EMG analysis
- Real-time wearable systems

---

## Dataset Requirements

- Multi-channel EMG
- Time-series signals
- Labelled word/action classes
- Publicly available
- Research-grade quality

---

## Candidate Datasets

### 1. Ninapro Dataset
Type: Hand/gesture EMG
Use: Initial EMG preprocessing and ML testing

### 2. PhysioNet EMG Datasets
Type: Biomedical EMG signals
Use: Signal processing experiments

### 3. Facial EMG Datasets
Type: Facial muscle activation
Use: Silent speech research

### 4. Silent Speech Interfaces Dataset
Type: Speech-related EMG
Use: Final ASV model training

---

## Planned Workflow

Public Dataset
→ Signal Preprocessing
→ Feature Extraction
→ ML Training
→ Real Hardware Integration
→ Custom Fine-Tuning
