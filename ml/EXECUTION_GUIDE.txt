### **Data Processing**
✅ Handles ~12.5M rows with chunking  
✅ Auto-detects EMG channels  
✅ Intelligent missing value handling  
✅ Outlier detection (IQR method)

✅ Sliding window segmentation (512 samples, 256 ms)

✅ 8 hand-crafted features per channel

## 🔧 Configuration

All scripts are configurable. Examples:

### **Modify Window Size**
```python
# 09_segment_signals.py
WINDOW_SIZE = 512    # Change to 256, 512, 1024, etc.
OVERLAP = 0.5        # Change to 0.25, 0.5, 0.75
```

### **Tune ML Models**
```python
# 11_train_real_model.py
RandomForestClassifier(
    n_estimators=200,  # Increase for better accuracy
    max_depth=20,      # Deeper trees = complex patterns
    random_state=42
)
```

### **Adjust Preprocessing**
```python
# 08_preprocess_real_emg.py
data_clean = preprocessor.remove_outliers(
    threshold=2  # Stricter: 1.5-3.0 range
)
```

## 💡 Pro Tips

### **For Better Results**
- Use longer signal samples for more windows
- Add more preprocessing steps if needed
- Try different window sizes (256, 512, 1024)
- Experiment with model hyperparameters

### **For Faster Training**
- Use KNN instead of SVM
- Skip frequency-domain features
- Reduce feature count

### **For Better Accuracy**
- Collect more training data
- Use feature scaling/normalization
- Try ensemble methods
- Reduce class imbalance
